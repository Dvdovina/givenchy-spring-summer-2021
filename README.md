# Landing for Givenchy spring-summer 2021 collection
### Web page prototype for Givenchy featuring animated elements, burger-menu and interactive buttons.
The purpose of the page is to engage the visitors and potential buyers by demonstrating and showcasing the new collection through high-quality animations and images.

#### Technology Stack:
![JavaScript](https://img.shields.io/badge/javascript-%23323330.svg?style=for-the-badge&logo=javascript&logoColor=%23F7DF1E)
![CSS3](https://img.shields.io/badge/css3-%231572B6.svg?style=for-the-badge&logo=css3&logoColor=white) 
![HTML5](https://img.shields.io/badge/html5-%23E34F26.svg?style=for-the-badge&logo=html5&logoColor=white)

#### Features:
- Adaptive Design - made for desktop, tablet and mobile (1440px/768px/320px)
- Uses BEM component-based approach, Flexbox, Grid, Animation and Positioning


Link to [GitHub Pages](https://dvdovina.github.io/givenchy-spring-summer-2021/)

# Лэндинг коллекции Givenchy весна-лето 2021
### Прототип веб-страницы для Givenchy с анимированными элементами, бургер-меню и интерактивными кнопками.
Цель страницы — привлечь посетителей и потенциальных покупателей путем демонстрации новой коллекции с помощью высококачественной анимации и изображений.

#### Стек Технологий:
![JavaScript](https://img.shields.io/badge/javascript-%23323330.svg?style=for-the-badge&logo=javascript&logoColor=%23F7DF1E)
![CSS3](https://img.shields.io/badge/css3-%231572B6.svg?style=for-the-badge&logo=css3&logoColor=white) 
![HTML5](https://img.shields.io/badge/html5-%23E34F26.svg?style=for-the-badge&logo=html5&logoColor=white)

#### Функционал:
- Адаптивный дизайн - создан для настольных компьютеров, планшетов и мобильных устройств (1440 пикселей/768 пикселей/320 пикселей)
- Использует БЭМ, Flexbox, Grid, Animation и Positioning.
